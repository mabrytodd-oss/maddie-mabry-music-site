## Quick Start

### Deploy to Netlify (2 minutes):

1. Go to [Netlify.com](https://www.netlify.com/) and sign up
2. Click "Deploy manually"  
3. Drag the `maddie-mabry-site-v2` folder
4. Done! Your site is live

### Preview Locally:

1. Unzip the folder
2. Double-click `index.html` to open in your browser
3. Navigate through all sections

## Editing in VS Code

**Recommended Setup:**
```bash
1. Download VS Code: https://code.visualstudio.com/
2. Install "Live Server" extension
3. Open folder in VS Code
4. Right-click index.html → "Open with Live Server"
5. Edit files → Save → See changes instantly!
```

## Color Customization

To change colors, edit `styles.css`:

```css
:root {
    --sage-green: #bac7b4;          /* Background color */
    --sage-green-light: #cbd8c3;    /* Section backgrounds */
    --hunter-green: #556B2F;        /* Accent color */
    --dark-text: #2c2c2c;           /* Text color */
}
```
